# 共学日记 v1.5.0

发布日期：2026-08-05

## 更新内容

- 新增 52 段整点生活闲聊，覆盖上午、下午、晚上和零点。
- 自动避开 09:00、12:00、15:00、18:00、21:00 五个打卡点；零点后至早晨保持安静。
- 整点闲聊采用跨天轮换，同一时段需要约 4 至 8 天才会走完一轮。
- 新增 34 段功能语音，覆盖学习暂停、任务收尾、学习拉回、任务完成、整组完成和每日结算。
- 右键日记中的小鹿试听扩展到新的生活闲聊和积极反馈语音。
- 退役 12 段已经退出机制的旧录音，不再混入试听或安装包。
- 打卡、强监督和任务弹窗始终高于生活闲聊，不会同时叠加说话。
