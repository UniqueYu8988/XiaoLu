# 共学日记 v1.1.2

这次更新让小鹿在 YuQuiz 打开时真正“走到学习岗位”。

## 学习驻守点

- YuQuiz 打开后，自动保存小鹿当前的自由位置。
- 小鹿播放跑步动画，先水平、再垂直移动到预设的学习驻守点。
- YuQuiz 确认关闭八秒后，小鹿沿同样的折线路径返回打开网页前的位置。
- 使用相对主屏工作区坐标定位，兼容不同分辨率和显示缩放比例。

## 移动体验

- 自动移动速度约为每秒 `230` 个逻辑像素，跨屏移动更加从容。
- 自动奔跑期间窗口保持鼠标穿透，不会沿路遮挡其他程序。
- 手动拖动会立即中断自动路线，并在本轮网页关闭前停止自动接管。
- 所有目标位置继续受到主屏幕边界限制，不会进入副屏或跑出可用区域。
- 自由位置会持久保存，学习驻守点不会覆盖用户平时摆放小鹿的位置。

## 安装

下载 `xiaolu-study-mate-1.1.2-x64.msi` 并运行。安装程序会覆盖旧程序文件，同时继续使用原来的本机学习记录。

> 安装包未使用商业代码签名，Windows 可能显示“未知发布者”。
