# 共学日记 v1.3.0

本次更新把学习提醒整理为更明确的两种陪伴节奏。

- 09:05–12:00、15:05–18:00 为强监督时段；尚未开始时，小鹿会在桌面巡逻并随机提醒。
- YuQuiz 持续学习三分钟或完成第一题后，巡逻立即结束；有效学习中断满十五分钟后重新巡逻。
- 托盘菜单可临时暂停当前时段的强监督，应对临时安排。
- 21 点完成今日结算后，小鹿会以较慢节奏在桌面散步；学习时安静停下，结束两分钟后再继续。
- 新增 36 段离线角色语音，台词、语音和动作按同一条目绑定，避免随机错配。
- 学习启动时段统一为 09:00–12:00、15:00–18:00、18:00–21:00。
- 统计页新增默认开启的“小鹿巡逻”，并统一“小鹿自启”“小鹿做题”等设置名称。
- 打卡提示拥有最高优先级：进入有效打卡窗口时立即暂停巡逻，回应后再恢复应有状态。
- 学习记录固定为每页三格等高展示，充分利用页面空间且保持无滚动条。
- 修复日记关闭后首次自动移动可能停在单帧的问题，并清除日记人物脚底的裁切阴影。

所有新语音仍在本地播放，不需要网络请求，也不会上传学习数据。
