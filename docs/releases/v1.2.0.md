# 共学日记 v1.2.0

这次更新把小鹿从“会去学习位置”继续扩展成了真正有空间感的学习监督搭子，也将近期积累的 YuQuiz、语音与启动陪伴整理进新版说明书。

## 重要提醒会来到你面前

- YuQuiz 首页提醒被忽略后，小鹿会跑到屏幕中央等待回应。
- 网页学习停顿较久时，小鹿会来到中央，用对应动作与语音轻轻提醒。
- 中央提醒停留约十五秒；YuQuiz 仍打开时返回学习驻守点，网页关闭时返回自由位置。
- 临时提醒不会覆盖已保存的位置，自动移动继续采用先水平、再垂直的折线路径。

## 自定义学习驻守点

- “今日”页右下角新增像素位置按钮。
- 把小鹿放到合适位置后点击按钮，即可保存为自己的学习驻守点。
- 保存成功后图标会变黄；以后打开 YuQuiz，小鹿会自动跑到这里。
- 自由位置与学习驻守点分别保存，网页关闭后仍会回到原来的桌面位置。

## 界面与说明书

- 进一步压缩统计卡片高度，让语音区、音量、开机自启、YuQuiz 开关和隐私说明完整显示在一屏内。
- 说明书升级为 v1.2.0，新增学习启动、离线语音、YuQuiz 状态、题量规则、自动移动和自定义驻守点说明。
- README 改为优先完整展示图文说明书，安装、开发与授权信息移到说明书之后。

## 安装

下载 `xiaolu-study-mate-1.2.0-x64.msi` 并运行。安装程序会升级现有版本，并继续使用原来的本机学习记录、书签、任务和位置设置。

> 安装包未使用商业代码签名，Windows 可能显示“未知发布者”。
