# 共学日记 v1.1.3

这是一次针对学习驻守返程的补丁更新。

## 修复

- 修复普通点击小鹿也会立即触发“开始拖动”的问题。
- 只有鼠标移动超过四个像素后才进入真正的拖动状态。
- 避免点击或双击清空返程目标、把学习驻守点错误保存为自由位置。
- YuQuiz 返回 `study_state=closed` 后立即开始返程，不再额外等待八秒。
- `active_session` 只表示仍有可继续任务，不再影响学习位置与动作状态。
- 返程目标优先使用本轮出发位置，必要时回退到持久保存的自由位置。

## 安装

下载 `xiaolu-study-mate-1.1.3-x64.msi` 并运行。安装程序会保留原有学习记录和位置设置。

> 安装包未使用商业代码签名，Windows 可能显示“未知发布者”。
