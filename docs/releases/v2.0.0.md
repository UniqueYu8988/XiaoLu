# 共学日记 v2.0.0

2.0.0 将共学日记从 YuQuiz 做题搭子升级为面向 YuReader 的桌面学习助理。

## YuReader 联动

- 同步阅读、做题、单词、口腔背诵、错题攻坚与三门学科进度。
- 今日任务改为阅读、综合、做题三枚动态书签，按实时百分比由灰白恢复颜色。
- 达到 100% 后自动收入收藏，并显示轻量像素粒子与对应离线语音。
- YuReader 后端未运行时，小鹿会先启动服务并通过健康检查，再复用或打开浏览器标签页。

## 今日、待办与记录

- 今日结算新增综合完成度、两项清关、在场次数和口腔、英语、政治三科进度。
- 单词数量可从共学日记写回 YuReader。
- 普通事项独立为“待办”，每日刷新项目才参与日常提醒。
- 学习记录兼容新旧两种日记格式，统计收敛为累计学习、打卡、双人书签和背词。

## 打卡与监督

- 五次打卡仍采用正负五分钟窗口。
- 打卡时必须处于手动计时、YuReader 学习或查询状态。
- 09:00、18:00、21:00 若学习台未打开，会自动启动 YuReader。
- 修复强监督只计算前台唤醒却未执行的问题；首页、阅读、暂停、查询和关闭状态均有明确判定。

## 界面、动作与声音

- 新增三枚学科贴纸、三书签任务页和像素粒子完成效果。
- 学习驻守点缩小并移到今日页面中央下方。
- 新增阅读/综合目标、口腔背诵和错题攻坚语音。
- 未完成目标不再因为旧时间戳提前闪烁。

## 安装

下载 `xiaolu-study-mate-2.0.0-x64.msi` 安装。学习记录保存在独立的 `%APPDATA%\xiaolu-desktop-pet`，升级不会清除个人数据。
