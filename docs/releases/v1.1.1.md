# 共学日记 v1.1.1

这是一次针对学习启动陪伴的修复与节奏优化版本。

## 修复

- 修复重新点击“开始”后仍保留上一轮最终提醒状态，导致新一轮提醒无法出现的问题。
- 自动识别并修复“最终提醒时间早于本次启动时间”的旧数据，不需要手工修改学习记录。
- 重新开始启动仪式时会清除已经失效的完成、跳过和提醒游标。

## 提醒节奏

- YuQuiz 停留在首页或学习总览时，每十分钟温和提醒一次，直到进入具体学习内容。
- 进入题目、教材阅读、错题或模拟考试后，视为已经开始，不再触发五分钟启动催促。
- 已进入学习内容但长时间停滞时，三十分钟后再提醒；之后至多每三十分钟提醒一次。
- 用户离开电脑时不播放拉回语音，恢复操作后再继续提醒。
- 首页拉回与题库停滞提醒复用现有离线语音，不增加在线服务或网络依赖。

## 安装

下载 `xiaolu-study-mate-1.1.1-x64.msi` 并运行。安装程序会覆盖旧程序文件，但继续使用原来的本机学习记录。

> 安装包未使用商业代码签名，Windows 可能显示“未知发布者”。
