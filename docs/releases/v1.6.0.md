# 共学日记 v1.6.0

这一版把“每日悬赏”重建成自动学习目标，也让记录与 YuQuiz 笔记统计真正连成一条完整的数据链。

## 主要更新

- 两枚单人书签分别绑定每日学习时长与做题数量，达标后自动获得；两项目标同日完成时自动获得双人书签。
- 今日结算新增正确率、笔记条数与净新增正文字符数，只需手动留下一句话。
- 学习记录合并目标与普通任务，新增笔记条数；每天的一句话可在记录页双击补写或修改。
- 累计统计新增 YuQuiz 可读正文字符数，直接读取 companion API 的累计口径，不扫描笔记文件。
- 新增 12 条离线语音，覆盖学习目标、做题目标、双目标与今日结算。
- 更新像素图标、设置页、任务页、记录分页与说明书真实界面截图。

## YuQuiz 接口口径

- 今日数据：`today_note_entries`、`today_note_characters`
- 累计数据：`total_note_entries`、`total_note_characters`、`total_note_files`
- 事件接口只驱动答题动作和整组完成提醒，不参与题量累计。

所有数据仍只保存在本机；发布内容不包含真实日记、任务、位置、数据库、日志或录音源文件。
