# 共学日记 Android 1.0.0

手机伴侣端的首个正式功能版本。Windows 软件版本仍为 2.0.4；本次不包含新的 Windows 安装包。

- 今日、任务、待办、统计，以及书签、历史和得分规则。
- 在线新增、编辑、完成、每日刷新和删除待办；今日背词总数回写 YuReader。
- 两款 2×2 正方形像素插画组件：今日进度、学习时长，各五档，共十张透明底半身插画；保留真实超额数值。
- 页面过渡、尽量原位刷新、应用长按快捷入口和文字分享待办草稿。
- 默认关闭的分级手机提醒：9、15、21点，约定提醒每轮最多三次，可推迟或当天休息。
- 五页精简 PDF：移除整页界面截图，以角色、书签和组件素材介绍桌面与手机功能。

## 安装与连接

下载 APK 覆盖旧版，首次安装需允许来自该来源的安装。安装包沿用开发期签名，不是商店发行包。电脑需运行支持手机配对的共学日记，手机和电脑连接同一 Tailscale 网络。电脑托盘点击“手机配对”，在手机填写 HTTPS 地址与六位配对码。公开 APK 不包含私人预设网址、令牌、日记、原始录音或个人数据。

长按手机桌面添加“小鹿 · 今日进度”“小鹿 · 学习时长”。更新旧组件后可重新添加。背景同步和通知会受省电策略影响；组件不自行计时，离线不能修改电脑记录。手机提醒需系统通知授权，不使用强制锁机或无障碍权限。

APK 编译、Android 静态检查、15项组件分档检查、11项提醒策略检查及桌面全量测试通过。用户已确认前一构建的页面与组件体验；1.0.0 公共地址填写和系统后台行为仍需各设备实际验收。
