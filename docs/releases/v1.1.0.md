# 共学日记 v1.1.0

这次更新把小鹿从“记录学习”进一步推进为“帮助开始学习”的桌面搭子。

## 新增

- 上午、下午、晚上各一次轻量学习启动陪伴；支持立即开始、十分钟后提醒和跳过本段。
- 启动后陪伴至 YuQuiz 第一题完成，成功后停止催促并播放特别反馈。
- 62 条完全离线的角色语音，覆盖固定打卡、学习启动、YuQuiz、任务、悬赏与晚间结算。
- 日记顶部人物随机语音互动，并匹配挥手、跳跃、等待或回顾动作。
- 语音开关、音量调节以及防重叠播放。
- 桌面气泡使用统一像素字体，并依据真实语音时长逐字显示文字。

## YuQuiz 联动

- 使用 `/api/companion/status` 的 `today_questions` 作为每日题量唯一来源。
- 事件游标只驱动答对、答错和整组完成动作，不再参与题量计算。
- 支持 ready、learning、consulting、paused、closed 状态与网页心跳自恢复。
- 新增本机即时唤醒通道，降低答题动作和复制咨询状态的响应延迟。
- 手动学习与网页学习继续按天累计，不因联动切换而覆盖。

## 体验优化

- 启动提醒改为紧凑的纯紫色像素图标，保留悬停说明和键盘可访问性。
- 气泡预留最终尺寸，逐字显示时不会不断跳动。
- 操作图标在文字完成后出现；减少动态效果模式下直接显示完整文字。
- 原始语音母带不进入仓库，安装包只包含切分压缩后的离线片段。

## 安装

下载 `xiaolu-study-mate-1.1.0-x64.msi` 并运行。安装程序会沿用现有应用身份，学习记录保存在原来的本机数据目录中。

> 安装包未使用商业代码签名，Windows 可能显示“未知发布者”。
