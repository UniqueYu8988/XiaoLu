# 手机桌面小组件：双主题插画设计

本轮设计稿，不改变桌面角色动画。两款组件都默认请求 2×2，奶油底、大圆角；从上到下依次为数据、阶段台词、横向透明底插画。数字与台词由应用绘制，不烘焙进图片。正常状态隐藏同步时间，断线／过期时只显示小标记，不能把昨日缓存伪装成今日实时值。

## 今日进度

使用今日综合完成度，保留超过 100% 的真实值。分档边界无重叠：0–20%（含20）、大于20且小于40%、40–79.99%、80–99.99%、100%以上。

| 档位 | 台词 | 插画 |
| --- | --- | --- |
| 0–20% | 我陪你，慢慢开始。 | 从横向书本后探头，挥手邀请 |
| >20–<40% | 已经走起来啦。 | 翻书写笔记，轻快的小星星 |
| 40–<80% | 看，我们越来越近了。 | 认真投入，书页和星星绕着半身角色 |
| 80–<100% | 就快把今天点亮啦。 | 双手捧着即将点亮的大星星 |
| ≥100% | 今天的约定，做到啦！ | 抱着金色书签，张开双臂庆祝 |

## 今日时长

使用接口提供的今日学习秒数，不由组件自行递增；分档采用左闭右开，10小时以上继续使用第五档，数据不封顶。

| 档位 | 台词 | 插画 |
| --- | --- | --- |
| 0–<2小时 | 陪你翻开今天。 | 轻松趴在展开的书上，托腮 |
| 2–<4小时 | 已经有点学者气质啦。 | 像小老师一样拿笔，旁边一叠书 |
| 4–<6小时 | 知识开始绕着你转啦。 | 书本与笔记横向环绕，俏皮认真 |
| 6–<8小时 | 学进小宇宙，也记得歇歇。 | 半身角色驾着书本，知识星星绕行 |
| ≥8小时 | 今天好投入，抱抱再休息。 | 夸张知识小宇宙，角色温柔张手，非疲惫惩罚 |

## 素材约束

- 保留栗色丸子头、侧分刘海、紫色格子衬衫和亲切的大眼睛。
- 清晰像素轮廓、有限色板、阶梯色阶；半身或大头构图，不要长腿占空间。
- 单张横向约3:2；主体和道具尽量占满有效面积，边缘留安全距离。
- PNG真实透明背景；无文字、数字、按钮、底板、背景景色或水印。
- 十档分别生成，首张作为一致性锚点；逐张检查小尺寸可读性。
- 本轮使用内置生图工具。完整共享提示词与各档场景提示词保存在素材目录，便于后续重做。
